The Facilities section (`id="facilities"`) sits directly below the Programs section and uses a negative top margin (`margin-top: -2.5rem`) to overlap it slightly, reinforcing the layered card aesthetic. The layout splits into two columns on tablets: a text-and-icon introduction on the left and a side-by-side court card gallery on the right. The body paragraph word-fades in word by word as the section enters the viewport, and the court photos scale up subtly on hover.

## Court cards

| Card | CSS modifier | Title | Description |
|---|---|---|---|
| Redline Clay | `.court-cap.clay` | Redline Clay | A fast outdoor clay court tuned for long, physical rallies. |
| Harbor Court | `.court-cap.blue` | Harbor Court | A sheltered hard court built for precision and night play. |

Both cards use the same inview spring (`tension: 180, friction: 26`, from `{ opacity: 0, y: 48 }`), but Harbor Court has a 140 ms delay so it settles after the clay court, reading left-to-right.

**To swap a court image**, replace the `src` attribute on the `<img>` inside the relevant `<figure>`. Update the `alt` text to accurately describe the new image. The image fills its container via `object-fit: cover` at a fixed `aspect-ratio: 3/4`.

## `.court-cap` glassmorphism overlay

Each court card has an absolutely-positioned `<figcaption>` that sits 0.75 rem from the bottom and sides of the card. The two colour variants are:

```css
/* Clay court: brand-deep tint */
.court-cap.clay {
  background: rgba(15, 47, 99, 0.4);
}

/* Hard court: teal tint */
.court-cap.blue {
  background: rgba(11, 110, 151, 0.55);
}

/* Shared caption styles */
.court-cap {
  position: absolute;
  left: .75rem; right: .75rem; bottom: .75rem;
  border-radius: .75rem;
  backdrop-filter: blur(8px);
  color: #fff;
  padding: .75rem 1rem;
}
.court-cap b    { display: block; font-size: .875rem; font-weight: 500; }
.court-cap span { font-size: .65rem; opacity: .85; }
```

To add a third court card, duplicate a `<figure class="court">` block, set new `data-delay`, update the image and caption text, and choose or create a `.court-cap` colour variant.

## `facBody` word-fade animation

The body paragraph animates in word by word rather than as a single block. The script reads the element's initial `textContent`, clears it, then rebuilds it as individual `<span class="wfade">` nodes — one per word — each with a calculated CSS transition delay:

```js
const facBody = document.getElementById("facBody");

(function () {
  const text = facBody.textContent.trim();
  facBody.textContent = "";

  const words = text.split(" ").map((w, i) => {
    const s = document.createElement("span");
    s.className = "wfade";
    s.textContent = w;
    // base delay 250 ms + 28 ms per word
    s.style.transition =
      `transform 700ms ${EASE.easeOutQuart} ${250 + i * 28}ms,
       opacity  700ms ${EASE.easeOutQuart} ${250 + i * 28}ms`;
    facBody.appendChild(s);
    facBody.appendChild(document.createTextNode(" ")); // preserve spaces
    return s;
  });

  const io = new IntersectionObserver(en => {
    if (en[0].isIntersecting) {
      words.forEach(w => w.classList.add("go")); // triggers CSS transition
      io.disconnect();
    }
  }, { threshold: 0.2 });

  io.observe(facBody);
})();
```

The `.wfade` class starts each word at `translateY(18px)` and `opacity: 0`. Adding `.go` transitions both properties to their natural values:

```css
.wfade     { display: inline-block; transform: translateY(18px); opacity: 0; }
.wfade.go  { transform: translateY(0);   opacity: 1; }
```

<Tip>
To change the cascade speed, adjust the `28` ms-per-word multiplier. Lower values make words appear more simultaneously; higher values create a more pronounced typewriter effect. The base delay of `250 ms` gives the heading time to begin animating first.
</Tip>

## Hover scale on court images

Both court `<figure>` elements carry the `data-hoverscale` attribute. After the DOM is built, a single selector applies a spring-powered hover effect to every element with that attribute:

```js
document.querySelectorAll("[data-hoverscale]").forEach(fig => {
  hover(fig, fig.querySelector("img"), { scale: 1 }, { scale: 1.03 }, [300, 22]);
});
```

The image scales from `1.0` to `1.03` on hover — subtle enough to not clip outside the card's `overflow: hidden` boundary.
