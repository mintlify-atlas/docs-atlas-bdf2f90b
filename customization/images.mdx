title: "Swapping and Optimising Images in Baseline"
sidebarTitle: "Images"
description: "How to replace hero backgrounds, court photos, coach portraits, gear slider images, and member avatars in Baseline's HTML and JavaScript data arrays."
---

Every image in Baseline is either an **inline `<img>` tag** in the HTML markup or a **URL string inside a JavaScript array**. There is no image-processing pipeline or asset manifest — to swap an image, replace the `src` attribute value or the URL string, save, and reload. The sections below cover each image location in the order it appears in `index.html`.

---

## Hero background

The full-bleed hero background is an `<img>` inside the `.hero-plate` wrapper:

```html
<div class="hero-plate" id="heroPlate">
  <img
    src="https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/hero/hero-court.webp"
    alt="Player lunging for a shot on a hard court"
    fetchpriority="high"
    loading="eager"
  >
</div>
```

Replace the `src` value with your own image URL or a relative path (e.g. `hero.jpg`). Key points:

- Keep `fetchpriority="high"` and `loading="eager"` — these attributes tell the browser to load the hero image immediately, which is critical for Largest Contentful Paint performance.
- The plate is animated with a CSS parallax (`top: -16%; height: 132%`) so the image must be taller than the viewport. Use a portrait or landscape photo that is at least **1400 × 1800 px** for best results.
- Update the `alt` attribute to describe your replacement image accurately.

## Collection slider images

The hero bottom-right slider is populated by the `collections` JavaScript array. Each object has an `img` field pointing to a CDN URL:

```js
const collections = [
  {
    img: `https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/2.webp`,
    brand: "Baseline Pro",
    title: "Featured Gear",
    cta: "Shop the kit",
    alt: "Player driving a backhand on a hard court"
  },
  {
    img: `https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/3.webp`,
    brand: "Court Series",
    title: "Summer Drop",
    cta: "View the line",
    alt: "Player stretching for a forehand on clay"
  },
  {
    img: `https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/5.webp`,
    brand: "Academy Kit",
    title: "Junior Range",
    cta: "Browse juniors",
    alt: "Player set in a ready stance on clay"
  }
];
```

Replace the `img` value for any entry with a new URL or relative path. The thumbnail is rendered at **3.5 rem × 3.5 rem** with `border-radius: 0.75rem` and `object-fit: cover`, so any square-ish photo works. Always update the `alt` field to match your new image.

## Trust / coach images

The coaching carousel in the Trust section is driven by the `trustSlides` array. Each entry has an `img` field for the coach portrait:

```js
const trustSlides = [
  {
    headline: ["Expert", "Result-", "Driven", "Coaching"],
    img: `https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/5.webp`,
    name: "Marco Vidal",
    role: "Head Coach",
    alt: "Head coach set in a ready stance on clay"
  },
  {
    headline: ["Sharper", "Faster", "Stronger", "Player"],
    img: `https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/4.webp`,
    name: "Elena Sokolova",
    role: "Performance Coach",
    alt: "Performance coach following through on a serve"
  },
  {
```

## Testimonial avatars

The `testis` array contains testimonial data. In the current template, testimonial cards display a quote, name, and role — **no avatar image is rendered by default**. If you extend the template to include member photos, you would add an `img` field to each entry in the array:

```js
const testis = [
  ["I added a level to my serve in one season. The coaching is detailed and it actually sticks.", "Priya Anand",   "Performance Squad"],
  ["Best courts in the city and a team that treats every member like a competitor.",              "Lukas Brenner", "Adult Clinics"],
  ["My daughter went from shy beginner to club champion. Worth every minute.",                    "Dana Okafor",   "Parent, Junior Development"]
];
```

The member avatar visible in the hero bottom-right card is a **separate `<img>` tag** in the HTML:

```html
<div class="glass member" id="memberCard">
  …
  <img
    src="https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/1.webp"
    alt="Player waiting to return on a clay court"
    loading="lazy"
  >
</div>
```

Replace the `src` to swap the member card photo. It renders at **4 rem wide** with `aspect-ratio: 3/4`.

## Court gallery images

The Facilities section shows two court cards, each containing an `<img>` tag nested inside a `<figure class="court">`:

```html
<!-- First court card -->
<figure class="court" …>
  <img
    src="https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/1.webp"
    alt="Player on the baseline of an outdoor clay court"
    loading="lazy"
  >
  <figcaption class="court-cap clay">
    <b>Redline Clay</b>
    <span>A fast outdoor clay court tuned for long, physical rallies.</span>
  </figcaption>
</figure>

<!-- Second court card -->
<figure class="court" …>
  <img
    src="https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/4.webp"
    alt="Player following through on a blue hard court"
    loading="lazy"
  >
  <figcaption class="court-cap blue">
    <b>Harbor Court</b>
    <span>A sheltered hard court built for precision and night play.</span>
  </figcaption>
</figure>
```

Both cards use `aspect-ratio: 3/4` with `object-fit: cover`. Swap `src` values to show your own courts. The small facilities icon above the section heading is also an `<img>`:

```html
<img
  class="fac-icon"
  src="https://api.getlayers.ai/storage/v1/object/public/public/assets/baseline-88535e4000/3.webp"
  alt="Player stretching for a forehand on clay"
  loading="lazy"
>
```

This renders at **4 rem × 4 rem** with `border-radius: var(--radius-card)` and `object-fit: cover`.

## Image format recommendations

| Use case               | Recommended format | Recommended dimensions     |
|------------------------|--------------------|----------------------------|
| Hero background        | WebP               | ≥ 1400 × 1800 px           |
| Coach / court cards    | WebP               | Portrait, e.g. 600 × 800 px (aspect 3/4) |
| Slider thumbnails      | WebP               | Square or near-square, e.g. 200 × 200 px |
| Facilities icon        | WebP               | 100 × 100 px (square)      |

**Lazy loading** is already applied via the `loading="lazy"` attribute on every image that is not in the initial viewport. The hero image uses `loading="eager"` intentionally — do not change this.

All coach and court card images use a **3/4 portrait aspect ratio** enforced by CSS. Supplying images at this ratio avoids unexpected cropping.

---

<Note>
If you are self-hosting images, place them in the **same directory** as `index.html` and reference them with relative paths, for example:

```html
<img src="hero.webp" alt="…">
```

```js
img: `coaches/marco.webp`
```

Relative paths are resolved from the location of `index.html`, so a flat directory structure is the simplest approach.
</Note>
