Baseline is a production-quality marketing landing page for a tennis club and academy. The entire site lives in one HTML file with no build step, no bundler, and no framework — just HTML, inline CSS, and vanilla JavaScript. Drop it on any static host and you're live.

## What's inside

Baseline ships every feature a tennis club landing page needs, with no external dependencies beyond a CDN-loaded smooth-scroll library.

  <Card title="Spring Animations" icon="wand-magic-sparkles" href="/customization/spring-engine">

  <Card title="Smooth Scroll" icon="scroll" href="/customization/smooth-scroll">

## Get started in three steps

<Steps>
  <Step title="Clone or download the repo">
    Download `index.html` from [GitHub](https://github.com/Vishen-dart-coder/Baseline) or clone the repository.
  </Step>
  <Step title="Serve over HTTP">
    Run `python3 -m http.server 8000` (or any static server) and open `http://localhost:8000/index.html` in your browser. A plain `file://` URL will block the ES module import for Lenis.
  </Step>
  <Step title="Edit content">
    Open `index.html` and update the JavaScript data arrays (`programs`, `stats`, `testis`, `trustSlides`, `collections`) and the CSS custom properties under `:root` to match your club's brand.
  </Step>
</Steps>

<Note>
  Baseline is intentionally a single-file prototype. All markup, styles, and scripts are co-located in `index.html` — there is no build step to run and no dependencies to install.
</Note>
